# Pixel Skill Assets

These PNG files are original placeholder-replacement sprites made for this project.

Visual direction was chosen after checking free/name-your-own-price pixel asset packs on Ansimuz itch.io, including the free sample pack pages. No external sprite pixels were copied into these files.

Asset mapping:

- `basic_bolt.png`: base hero and clone projectile.
- `kunai.png`: 苦无 projectile.
- `shuriken.png`: 大手里剑 area center.
- `fireball.png`: 火遁.豪火球 projectile.
- `phoenix_ember.png`: 火遁.凤仙花 projectile.
- `burn_patch.png`: 火遁.凤仙花 burn area.
- `earth_wall.png`: 土遁.土流壁 wall.
- `swamp_pool.png`: 土遁·黄泉沼 area.
- `chakra_orb.png`: active skill pool cell.
- `spent_orb.png`: spent skill pool cell.
- `enemy_imp.png`, `enemy_elite.png`, `enemy_boss.png`: enemy placeholders.
- `preview_contact_sheet.png`: local preview sheet, not loaded by the game.
