# Neon Tower Defense H5

这是一个移动端竖屏塔防小游戏。当前主入口已调整为 H5：直接打开 `index.html` 即可运行，不依赖 Godot 导出或前端构建工具。

## 当前入口

- H5 入口：`index.html`
- H5 样式：`web/styles.css`
- H5 配置：`web/config.js`
- H5 存档：`web/progress.js`
- H5 奖励池：`web/rewards.js`
- H5 主运行时：`web/game.js`
- 旧 Godot 工程：`project.godot`、`scenes/`、`scripts/`

Godot 文件仍保留，作为历史实现和玩法规则参考；当前浏览器版本的可运行入口是 `index.html`。

## H5 文件拆分

- `index.html` 只保留页面结构和脚本引用。
- `web/styles.css` 负责所有页面样式、弹窗、宝箱图标和奖励开启特效。
- `web/config.js` 维护关卡、宝箱、奖励数量、技能权重、升级数值、稀有度、经验和死神 Boss 配置。
- `web/progress.js` 维护 `localStorage.neonTowerProgress` 的读写与默认结构。
- `web/rewards.js` 维护宝箱奖励数量、稀有度和 3 选 1 基础升级卡池。
- `web/game.js` 维护 Canvas 主循环、输入、战斗推进和绘制。

## 如何运行

在浏览器中打开：

```text
index.html
```

如果浏览器限制本地文件访问，也可以在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## H5 玩法

- 首次进入主界面，顶部显示本地账号的当前战机、金币、抽奖券和战机解锁数量；新存档默认金币为 `999999`。
- 主界面提供“开始游戏”和“战机信息”：开始游戏弹出战机选择，战机信息以独立页面展示每架战机的基础攻击、射速、攻击数量、命中特点和击败特点。
- 战机信息页页脚可进入升级界面；升级界面横向展示基础参数、命中技能和击败特点的升级或解锁卡片，按钮使用金币图标和价格展示，点击后会扣除金币并写入本地存档；升级界面提供“重置”按钮，可清空当前战机升级进程。
- 默认只解锁基础战机；火焰、冰霜、爆炸、闪电、穿甲、裂变、引力战机可在战机选择页用金币解锁。
- 战机位于底部，可用 `A` / `←`、`D` / `→` 或触屏点击/拖动移动。
- 点击或拖动画布会把战机移动到触点横向位置。
- 战机自动向上发射子弹。
- 中央霓虹墙体把命中分为左右两侧：
  - 左侧命中宝箱，击碎后弹出 `1 / 3 / 5` 个可开启宝箱，下一轮宝箱最大血量按 `1.5` 倍并向上取整到 `100` 递增。
  - 右侧命中敌人，按候选排序结算伤害。
- 宝箱奖励轮数为 `1 / 3 / 5` 次，概率为 `80% / 15% / 5%`。
- 点击每个宝箱后进入 3 选 1，选择后继续打开下一个宝箱或恢复战斗。
- 击败怪物获得经验，升级后从 3 张卡中选择一个强化。
- 升级卡分为蓝色普通、紫色史诗、橙色传说，概率为 `70% / 25% / 5%`。
- 当前只保留基础强化：子弹数量、子弹射速、子弹穿透、子弹伤害、血量恢复；子弹数量和穿透只会出现在宝箱奖励中，每次固定 `+1`。子弹数量卡为“子弹数 +1，伤害降低25%”。子弹数量最终上限为 `5`，子弹穿透上限为 `3`。
- 不同战机提供额外命中特效：火焰持续伤害、冰霜减速、爆炸范围伤害、闪电链、穿甲连续命中攻速、裂变分裂伤害、引力击退；引力击退为旧基础值和升级值的 `8%`，击败特点需要在升级界面消耗金币解锁后才会生效。
- 普通敌人、精英怪在每波混合刷出，单体 Boss 按阶段推进；普通怪基础血量为 `4`，精英怪基础血量为 `8`。当普通怪当前生成血量小于等于“当前单轮发射总伤害 * 2”并持续 `5` 秒后，后续普通/精英怪血量增加 `50%`。怪物行进速度为上一版配置的 `15%`，只有 Boss 显示血条。
- 常规 Boss 在死神 Boss 出现前会继续循环波次；开局 5 分钟后刷新死神 Boss，击败死神 Boss 后通关结算。
- 普通怪和精英怪到达战机水平线或触碰战机会造成战机伤害并移除，Boss 和死神 Boss 触碰战机或到达战机水平线时失败。
- 清空死神 Boss 后通关，死亡和通关都会结算金币，通关额外获得抽奖券。

## 视觉风格

当前 H5 版本使用 `assets/warPlane/` 下的战机图片素材：无 `_s` 后缀图片用于战机库选择界面，带 `_s` 后缀图片用于游戏内战机绘制。画面采用深色背景、霓虹线条、描边方块和菱形来表达宝箱、墙体与敌人。左侧宝箱绘制为宝箱图案，宝箱上方显示血条；宝箱击碎后的奖励弹窗使用烟花、彩蛋、星火和宝箱图标，3 选 1 卡片按子弹数量、射速、穿透、伤害展示不同图标，奖励界面减少额外内框线。

## 快速调参

主要数值集中在 `web/config.js`：

- `balance.chest`：宝箱初始血量、递增倍率、取整单位、单次命中扣血、击碎后奖励数量概率。
- `balance.upgradeCaps`：子弹数量和子弹穿透的运行时上限。
- `rarityDefs`：蓝色、紫色、橙色卡的出现概率。
- `upgradeOptions`：每个强化的出现权重、每个稀有度增加的数值和描述。
- `fighters` / `fighterEffects`：战机解锁价格和命中/击败特效数值。
- `balance.progression.xpRequirements`：每级所需经验。
- `balance.deathBoss`：死神 Boss 是否启用、出现时间、血量、速度、经验和金币。
