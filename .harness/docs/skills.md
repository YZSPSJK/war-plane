# 技能与升级文档

## 事实来源

- H5 升级运行时：`web/game.js`
- Godot 旧技能池与数值：`scripts/config/game_balance.gd`
- Godot 旧技能运行时：`scripts/levels/level1.gd`
- 旧草案来源：`docs/skill/技能.md`、`docs/skill/角色技能.md`

当前可运行 H5 版本已移除额外任务技能选择，只保留基础弹幕升级。Godot 旧技能池仍作为历史实现保留。

## H5 当前升级池

每次宝箱奖励或角色升级进入 3 选 1，候选只来自以下四类：

- 子弹数量：增加每轮发射的基础子弹数量。
- 子弹射速：缩短自动射击间隔。
- 子弹穿透：增加单发子弹可继续命中的敌人数。
- 子弹伤害：提高单发子弹伤害。

选择卡稀有度：

- 蓝色普通：`70%`
- 紫色稀有：`25%`
- 橙色传说：`5%`

稀有度只影响数值强度，不再引入新的技能机制。

## 宝箱奖励

- 左侧宝箱击碎后先弹出奖励宝箱和开启特效，而不是直接进入卡牌选择。
- 奖励宝箱数量概率：`1` 个 `80%`、`3` 个 `15%`、`5` 个 `5%`。
- 玩家点击一个奖励宝箱后进入 3 选 1。
- 选择完成后，如果还有奖励宝箱，继续回到宝箱界面；全部奖励完成后恢复战斗。

## 性能约束

- H5 当前不绘制持续技能区域、召唤物、毒、灼烧、减速等额外效果。
- Canvas 绘制避免每帧大量阴影、动态斜线和高数量粒子。
- 宝箱不绘制血条，只显示数字血量，减少 UI 绘制负担。

## 后续扩展建议

- 若恢复额外技能，应先做性能预算和开关，不要一次性恢复所有持续效果。
- 多角色差异点建议放在基础弹道、初始基础升级倾向和终局传说强化，而不是恢复复杂技能池。
