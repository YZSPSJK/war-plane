# 技能与升级文档

## 事实来源

- H5 升级运行时：`web/game.js`
- Godot 旧技能池与数值：`scripts/config/game_balance.gd`
- Godot 旧技能运行时：`scripts/levels/level1.gd`
- 旧草案来源：`docs/skill/技能.md`、`docs/skill/角色技能.md`

当前可运行 H5 版本已移除额外任务技能选择，只保留基础弹幕升级。Godot 旧技能池仍作为历史实现保留。

## H5 当前升级池

每次宝箱奖励或角色升级进入 3 选 1，候选来自以下五类：

- 子弹数量：只在宝箱奖励中出现，每次固定 `+1`，同时伤害降低 `25%`。
- 子弹射速：缩短自动射击间隔。
- 子弹穿透：只在宝箱奖励中出现，每次固定 `+1`。
- 子弹伤害：提高单发子弹伤害。
- 血量恢复：立即恢复当前战机血量，普通 `5`、史诗 `15`、传说 `30`，不超过最大血量。

选择卡稀有度：

- 蓝色普通：`70%`
- 紫色史诗：`25%`
- 橙色传说：`5%`

稀有度只影响数值强度，不再引入新的技能机制。

每个强化的出现权重、每个稀有度增加的数值和卡片描述均维护在 `web/config.js` 的 `upgradeOptions` 中。

基础强化受 `balance.upgradeCaps` 限制：子弹数量最终上限为 `5`，子弹穿透上限为 `3`；达到上限后对应卡片不再进入奖励候选池。由于奖励池包含血量恢复，子弹数量和子弹穿透都达到上限后仍能保持 3 选 1。等级提升奖励不会出现子弹数量和子弹穿透卡。

## H5 当前战机效果

- 基础战机默认解锁；基础攻击、射速、攻击数量、血量和命中强化可在战机升级页消耗金币提升，血量默认 `100`，每级血量升级增加 `20` 点最大血量。
- 火焰战机命中附加持续伤害，命中升级提升持续伤害；击败技能解锁后生成灼烧区域。
- 冰霜战机命中附加减速，命中升级提升减速数值；击败技能解锁后生成减速区域。
- 爆炸战机命中造成范围伤害并绘制爆炸冲击波，命中升级提升范围伤害；击败技能解锁后产生一次范围爆炸。
- 闪电战机命中触发闪电链，闪电链派生伤害不会继续触发新的闪电链，命中升级提升闪电链伤害；击败技能解锁后施放一次过载闪电。
- 穿甲战机命中同一目标时提高射速，切换目标重置；击败技能解锁后可在击败后保留攻速加成到下一目标。
- 裂变战机命中敌人时向周围敌人飞出分裂子弹，命中升级提升分裂子弹伤害；击败技能解锁后产生额外分裂子弹。
- 引力战机命中产生击退，当前击退距离为旧基础值和升级值的 `8%`；击败技能解锁后生成黑洞，将周围敌人拉向中心。

战机解锁价格维护在 `web/config.js` 的 `fighters`；战机效果数值维护在 `fighterEffects`；战机升级存档维护在 `localStorage.neonTowerProgress.fighterUpgrades`。
战机升级页提供“重置”按钮，可一键清空当前战机的升级进程；重置只影响升级字段，不改变战机拥有状态。

## 宝箱奖励

- 左侧宝箱击碎后先弹出奖励宝箱和开启特效，而不是直接进入卡牌选择。
- 宝箱最大血量随击碎次数递增：每轮按上一轮血量 `* 1.5`，再向上取整到 `100`。
- 奖励宝箱数量概率维护在 `web/config.js` 的 `balance.chest.rewardCounts`，默认 `1` 个 `80%`、`3` 个 `15%`、`5` 个 `5%`。
- 玩家点击一个奖励宝箱后进入 3 选 1。
- 选择完成后，如果还有奖励宝箱，继续回到宝箱界面；全部奖励完成后恢复战斗。

## 性能约束

- H5 当前只绘制战机带来的灼烧区域、冰片区域、爆炸冲击波、闪电链、分裂子弹和黑洞，不恢复旧技能池里的召唤物、毒等复杂效果。
- Canvas 绘制避免每帧大量阴影、动态斜线和高数量粒子。
- 玩家战机周身特效只使用少量轨道线段或标记，不新增持续粒子系统。
- H5 背景使用缓存画布，窗口尺寸变化时重建，普通帧只复用缓存。
- 宝箱上方绘制血条，不再绘制数字血量，减少文字重绘干扰。
- 奖励界面避免多层线框，仅保留卡片稀有度色条和必要图标。
- 奖励宝箱开启特效每轮宝箱只播放一次，并降低 DOM 动画节点数量，避免多次开启后持续占用渲染资源。

## 后续扩展建议

- 若恢复额外技能，应先做性能预算和开关，不要一次性恢复所有持续效果。
- 多角色差异点建议放在基础弹道、初始基础升级倾向和终局传说强化，而不是恢复复杂技能池。
