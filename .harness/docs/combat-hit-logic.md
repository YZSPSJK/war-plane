# 战斗命中判定规范

## 坐标与分区

- 关卡为 `Node2D`，主角、子弹、敌人均在 2D 世界坐标中更新。
- 中间墙体 `_wall_rect.get_center().x` 是命中分区边界。
- 子弹 `x < wall_center_x` 且类型为 `basic`、`kunai`、`clone_basic` 时，优先判定左侧技能池。
- 其他情况判定右侧敌人。

## 子弹生效条件

- 子弹生成后累计飞行距离达到 `projectile_arm_distance = 30.0` 才参与命中。
- 子弹超出 `_play_rect.grow(100.0)` 后移除。
- 默认基础射击按 `shoot_interval = 0.35` 秒循环发射。

## 左侧技能池命中

- 技能池可视化为 `10x10` 点阵。
- 点阵仅表达共享总血池，不做单格独立血量。
- 判定范围为 `_get_skill_grid_bounds().grow(PROJECTILE_HIT_RADIUS)`。
- 单次命中扣 `damage_to_skill_pool`。
- 技能池归零后重置为 `skill_pool_max_hp`，并调用技能解锁流程。

## 右侧敌人命中

候选收集：

- 普通敌人：使用 `SWARM_HIT_RADIUS`。
- 精英怪：使用 `ELITE_DOT_RADIUS`。
- Boss：使用 `BOSS_DOT_RADIUS`。
- 子弹中心到敌人中心距离小于等于 `PROJECTILE_HIT_RADIUS + enemy_radius` 即为命中候选。

候选选择：

1. 第一关键字：`x` 从小到大。
2. 第二关键字：同 `x` 时，`y` 从大到小。
3. 每次命中只选中一个目标。

## 伤害结算

设敌人剩余血量为 `A`，最终伤害为 `B`：

- `A - B <= 0`：移除敌人并增加击杀数。
- `A - B > 0`：更新敌人剩余血量。

最终伤害会受到黄泉沼护甲削弱影响；Boss 对控制与护甲削弱使用 `boss_control_reduction = 0.5`。

## 特殊弹体

- `kunai`：记录已命中过的敌人 ID，避免同一发苦无重复命中同一目标；穿透次数耗尽后消失，并附加毒效果。
- `fireball`：直击目标后，以命中点为中心造成范围伤害并击退。
- `phoenix`：直击目标后生成灼烧区域。
- `clone_basic`：分身发射的普通弹，命中规则与基础弹一致。

## 持续效果

- 毒：按敌人 ID 持续跳伤；目标不存在时移除效果。
- 大手里剑区域：对范围内敌人持续跳伤。
- 灼烧区域：对范围内敌人持续跳伤。
- 黄泉沼：范围内减速并提高受伤倍率。
- 土流壁：阻挡敌人移动，接触时扣墙体血量。

## 验收关注点

- 同一发非穿透子弹命中后必须移除。
- 苦无穿透时不得重复命中同一敌人 ID。
- 左右分区必须由墙体中心线决定，而不是屏幕中心。
- 多候选目标排序必须保持左到右、同列下到上。
