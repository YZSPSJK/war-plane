# 战斗命中判定规范

## 坐标与分区

- Godot 旧实现中关卡为 `Node2D`；当前 H5 实现中战机、子弹、敌人均在 Canvas 2D 坐标中更新。
- 中间墙体 `_wall_rect.get_center().x` 是命中分区边界。
- 子弹 `x < wall_center_x` 时，优先判定左侧宝箱。
- 其他情况判定右侧敌人。

## 子弹生效条件

- 子弹生成后累计飞行距离达到 `projectile_arm_distance = 30.0` 才参与命中。
- 子弹超出 `_play_rect.grow(100.0)` 后移除。
- 默认基础射击按 `shoot_interval = 0.35` 秒循环发射。

## 左侧宝箱命中

- 宝箱可视化为橙色霓虹宝箱图案，宝箱上方显示血条，不再绘制数字血量。
- 判定范围为 `chestBounds().grow(PROJECTILE_HIT_RADIUS)`。
- 单次命中扣血由 `web/config.js` 的 `balance.chest.damagePerHit` 配置，默认 `3`。
- 宝箱归零后 `state.chestsOpened` 增加，下一轮最大血量按上一轮血量 `* balance.chest.hpGrowthMultiplier` 后向上取整到 `balance.chest.hpRoundStep` 计算，并按 `balance.chest.rewardCounts` 弹出 `1 / 3 / 5` 个奖励宝箱。
- 点击每个奖励宝箱后进入 3 选 1 基础升级选择。

## 战机受伤判定

- 战机默认最大血量为 `100`，战机基础属性升级可提升最大血量。
- 普通怪触碰战机或到达战机水平线时造成 `5` 点伤害并移除。
- 精英怪触碰战机或到达战机水平线时造成 `10` 点伤害并移除。
- Boss 和死神 Boss 不结算伤害数值，接触战机或到达战机水平线直接失败。
- 血量恢复卡按普通 `5`、史诗 `15`、传说 `30` 点恢复，当前血量不超过最大血量。

## 右侧敌人命中

候选收集：

- 普通敌人：H5 当前使用 `balance.enemyVisuals.swarm.radius = 8`。
- 精英怪：H5 当前使用 `balance.enemyVisuals.elite.radius = 10`。
- Boss 和死神 Boss：H5 当前为单个大型目标，分别使用 `balance.enemyVisuals.boss.radius = 56` 和 `balance.enemyVisuals.deathBoss.radius = 68`。
- 子弹中心到敌人中心距离小于等于 `PROJECTILE_HIT_RADIUS + enemy_radius` 即为命中候选。

候选选择：

1. 第一关键字：`x` 从小到大。
2. 第二关键字：同 `x` 时，`y` 从大到小。
3. 每次命中只选中一个目标。

## 战机命中特效

- 基础战机：没有额外加成，只结算基础子弹伤害。
- 火焰战机：命中敌人后写入燃烧状态，按 `fighterEffects.flame` 周期性造成持续伤害；击败技能解锁后生成灼烧区域。
- 冰霜战机：命中敌人后写入减速状态，敌人下压速度乘以升级后的减速系数；击败技能解锁后生成冰片区域，区域内敌人受到伤害并减速。
- 爆炸战机：命中敌人后，以命中点为中心按 `fighterEffects.blast.radius` 对周围其他敌人造成范围伤害，并绘制独立的爆炸冲击波；命中升级提升范围伤害。
- 闪电战机：命中敌人后，从命中点向附近敌人跳转闪电链；闪电链造成的派生伤害不会继续触发新的闪电链，命中升级提升闪电链伤害，击败技能解锁后从死亡点触发一次过载闪电。
- 穿甲战机：命中同一目标时累加 `state.piercingFireRateBonus` 并缩短 `shootInterval()`；切换目标重置，击败技能解锁后可保留到下一目标。
- 裂变战机：命中敌人后，按距离选择附近最多 `fighterEffects.fission.targets` 个敌人，向目标飞出分裂子弹；分裂子弹命中后造成分裂伤害，但不再触发新的命中特效或击败被动，命中升级提升分裂伤害。
- 引力战机：命中敌人后产生击退，当前击退距离按旧基础值和升级值的 `8%` 结算；击败技能解锁后生成 `blackhole` 效果，持续期间将 `fighterEffects.gravity.radius` 范围内敌人拉向中心。

## 伤害结算

设敌人剩余血量为 `A`，最终伤害为 `B`：

- `A - B <= 0`：移除敌人并增加击杀数。
- `A - B > 0`：更新敌人剩余血量。

H5 当前最终伤害受本局“子弹伤害”升级、战机基础攻击升级和战机命中技能派生伤害影响。

普通怪基础血量为 `4`，精英怪基础血量为 `8`。当普通怪当前生成血量小于等于“当前单轮发射总伤害 * 2”并持续 `5` 秒后，后续刷出的普通怪和精英怪血量 `* 1.5`；如果涨血后仍持续满足该条件，可以继续触发下一次 `* 1.5`。普通怪刷怪间隔为 `0.54` 秒，精英怪刷怪间隔为 `0.78` 秒；精英怪基础下压速度 `9.0` 为普通怪 `7.5` 的 `120%`。普通和精英敌人从页面顶部外侧连续进入，下一波生成队列不等待屏幕清空。

## 特殊弹体

- 基础子弹：记录已命中过的敌人 ID，避免同一发子弹重复命中同一目标。
- 分裂子弹：由裂变战机派生，继承弹体移动和命中流程，生成时记录源敌人 ID，避免立刻回打源目标；命中后只结算分裂伤害，不继续派生。
- 子弹数量：只由宝箱奖励和战机升级增加；宝箱奖励每次固定 `+1`，并让最终伤害乘以 `0.75`，最终发射数量上限为 `5`。
- 子弹穿透：只由宝箱奖励增加；宝箱奖励每次固定 `+1`，穿透次数耗尽后消失，上限为 `3`。

## 持续效果

- 火焰灼烧区域和冰霜冰片区域存放在运行时 `state.effects`，随时间递减，结束后移除。
- 闪电链也使用 `state.effects` 保存短时折线，只负责视觉表现。
- 爆炸冲击波和黑洞也存放在 `state.effects`；黑洞每帧改变范围内敌人的位置，不直接造成伤害。
- 持续区域造成的伤害不再继续触发击杀区域，避免连锁区域无限扩散。

## 验收关注点

- 同一发非穿透子弹命中后必须移除。
- 子弹穿透时不得重复命中同一敌人 ID。
- 左右分区必须由墙体中心线决定，而不是屏幕中心。
- 多候选目标排序必须保持左到右、同列下到上。
- 普通怪和精英怪不显示血条，Boss 和死神 Boss 显示血条；敌人视觉使用 `assets/meteors/` 的像素陨石 PNG，碰撞仍以运行时半径结算。
- H5 版本验证时需要确认 Canvas 已绘制非空画面，且手机宽度下顶部状态卡片不遮挡左侧宝箱。
- 验证不同战机时，确认同一发子弹仍遵守穿透和命中 ID 去重规则。
