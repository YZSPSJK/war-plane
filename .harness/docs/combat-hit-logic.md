# 战斗命中判定规范

## 坐标与分区

- Godot 旧实现中关卡为 `Node2D`；当前 H5 实现中主角、子弹、敌人均在 Canvas 2D 坐标中更新。
- 中间墙体 `_wall_rect.get_center().x` 是命中分区边界。
- 子弹 `x < wall_center_x` 时，优先判定左侧宝箱。
- 其他情况判定右侧敌人。

## 子弹生效条件

- 子弹生成后累计飞行距离达到 `projectile_arm_distance = 30.0` 才参与命中。
- 子弹超出 `_play_rect.grow(100.0)` 后移除。
- 默认基础射击按 `shoot_interval = 0.35` 秒循环发射。

## 左侧宝箱命中

- 宝箱可视化为橙色霓虹线框。
- 判定范围为 `chestBounds().grow(PROJECTILE_HIT_RADIUS)`。
- 单次命中扣 `damageToChest = 3`。
- 宝箱归零后重置为 `chestMaxHp = 120`，并按 `80% / 15% / 5%` 弹出 `1 / 3 / 5` 个礼物。
- 点击每个礼物后进入 3 选 1 基础升级选择。

## 右侧敌人命中

候选收集：

- 普通敌人：使用 `SWARM_HIT_RADIUS`。
- 精英怪：使用 `ELITE_DOT_RADIUS`。
- Boss：H5 当前为单个大型目标，使用其运行时半径。
- 子弹中心到敌人中心距离小于等于 `PROJECTILE_HIT_RADIUS + enemy_radius` 即为命中候选。

候选选择：

1. 第一关键字：`x` 从小到大。
2. 第二关键字：同 `x` 时，`y` 从大到小。
3. 每次命中只选中一个目标。

## 伤害结算

设敌人剩余血量为 `A`，最终伤害为 `B`：

- `A - B <= 0`：移除敌人并增加击杀数。
- `A - B > 0`：更新敌人剩余血量。

H5 当前最终伤害只受基础“子弹伤害”升级影响。

## 特殊弹体

- 基础子弹：记录已命中过的敌人 ID，避免同一发子弹重复命中同一目标。
- 子弹穿透：由基础升级增加，穿透次数耗尽后消失。

## 持续效果

- H5 当前没有额外技能持续效果。

## 验收关注点

- 同一发非穿透子弹命中后必须移除。
- 子弹穿透时不得重复命中同一敌人 ID。
- 左右分区必须由墙体中心线决定，而不是屏幕中心。
- 多候选目标排序必须保持左到右、同列下到上。
- 普通怪不显示血条，精英怪和 Boss 显示血条。
- H5 版本验证时需要确认 Canvas 已绘制非空画面，且底部控制不遮挡主角活动区。
