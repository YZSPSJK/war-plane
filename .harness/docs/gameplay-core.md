# 玩法核心文档

## 事实来源

- 当前 H5 入口：`index.html`
- 当前 H5 样式：`web/styles.css`
- 当前 H5 配置：`web/config.js`
- 当前 H5 存档：`web/progress.js`
- 当前 H5 奖励池：`web/rewards.js`
- 当前 H5 主运行时：`web/game.js`
- 主玩法脚本：`scripts/levels/level1.gd`
- 体验关扩展脚本：`scripts/levels/level_experience.gd`（当前场景未挂载，见 `level-construction.md`）
- 数值配置：`scripts/config/game_balance.gd`
- 关卡配置：`scripts/config/level_catalog.gd`
- 进度存档：`scripts/core/level_progress.gd`

当前可运行入口已调整为 H5。Godot 脚本仍保留为历史实现与规则参考；浏览器版本的运行时规则以 `web/game.js` 为准。

## 核心循环

1. 进入关卡后 `GameManager.start_game()`，关卡立即开始。
2. 玩家控制底部主角横向移动，主角按固定间隔自动向上发射子弹。
3. 子弹按中间墙体中心线分流：
   - 左侧命中宝箱，扣减宝箱血量。
   - 右侧命中敌人，按候选排序选择唯一目标结算。
4. 宝箱归零后重置，先展示奖励宝箱，再触发 3 选 1 奖励选择。
5. 敌人按阶段刷出并持续下压；当前阶段清空后推进到下一阶段。
6. 击杀敌人累计经验，达到阈值后主角升级并触发 3 选 1 升级选择。
7. 敌人触碰主角或到达主角水平线时失败；Boss 阶段清空后通关并结算金币。

## 玩家控制

- 移动按钮：`MoveLeft`、`MoveRight`。
- 键盘：`A` / `Left` 左移，`D` / `Right` 右移。
- 触屏：点击或拖动时将主角移动到触点 `x`。
- 主角移动范围限制在 `_play_rect` 内，底部固定高度由 `_layout_world()` 计算。

## 成长与奖励

- 左侧宝箱基础血量：`chestMaxHp = 120`。
- 普通子弹命中宝箱时，每次扣 `damageToChest = 3`。
- 宝箱击碎后奖励选择轮数概率：
  - `1` 次：`80%`
  - `3` 次：`15%`
  - `5` 次：`5%`
- 宝箱击碎后先展示对应数量的奖励宝箱。点击每个宝箱后进入 3 选 1，选择后继续下一个宝箱或恢复战斗。
- 击杀经验：普通怪 `1`，精英怪 `6`，Boss `40`。
- 升级经验阈值：`[8, 18, 32, 50, 72, 98, 128, 162, 200]`。
- 升级时提供 3 张基础强化卡，稀有度概率为蓝色普通 `70%`、紫色稀有 `25%`、橙色传说 `5%`。
- 当前只保留基础强化：子弹数量、子弹射速、子弹穿透、子弹伤害。

## 敌人阶段

阶段由 `_wave_phase` 表示：

- `0`：普通敌人
- `1`：精英怪
- `2`：Boss

默认流程：

1. 第 `1~5` 波每波先刷普通敌人，再刷精英怪。
2. 第 5 波精英结束后进入 Boss。
3. Boss 清空后进入通关。

当前 H5 实现中普通、精英按随机横向位置逐个刷出；Boss 为单个大型目标并显示血条。旧文档中的固定矩阵语义仅作为早期原型参考，不作为当前代码事实。

## 宝箱

- 左侧宝箱以橙色霓虹线框显示，表达一个共享宝箱血量。
- 宝箱奖励池与升级奖励池一致，只包含四类基础强化。
- 宝箱奖励弹窗和 3 选 1 弹窗打开期间暂停战斗，完成全部奖励选择后恢复。

H5 版本使用 `localStorage.neonTowerProgress` 保存金币、关卡进度、选中角色和角色预留数据；Godot 版本使用 `user://level_progress.cfg`。

## H5 视觉规则

- 不再使用 `assets/pixel_skills/` 的像素素材。
- 主角使用霓虹线框五边形与内部折线表达。
- 宝箱使用橙色霓虹线框表达，宝箱下方显示数字血量，不显示血条。
- 宝箱击碎奖励弹窗使用烟花、彩蛋、星火和线框宝箱图标；3 选 1 卡片按强化内容显示不同图标。
- 普通敌人使用红色描边方块且不显示血条，精英与 Boss 使用菱形线框并显示血条。
- 中央道路与墙体使用青色霓虹描边和扫描线。

## 失败与通关

失败条件：

- 活动敌人与主角圆形碰撞。
- 活动敌人的底部到达主角水平线。

失败结果：

- 记录当前关卡失败次数。
- 清空子弹、分身和持续效果。
- 显示失败弹窗。

通关结果：

- 清空当前关失败次数。
- 写入关卡进度、金币并解锁下一关。
- 清空子弹并显示通关弹窗。

## 当前接入差异

- `scripts/levels/level_experience.gd` 定义了救援宝箱和“神罗天征”体验关逻辑。
- `scenes/levels/level_experience.tscn` 当前仍挂载 `scripts/levels/level1.gd`，且没有在场景中设置 `level_id = "level2_experience"`。
- 因此体验关扩展逻辑目前应视为“已编写但未接入场景”的能力，不能作为线上实际玩法事实。

## 验收关注点

- 修改刷怪或阶段推进时，验证普通、精英、Boss 互斥，不出现多个活动阶段同时压场。
- 修改宝箱时，验证左侧命中只扣宝箱，右侧命中只打敌人。
- 修改成长时，验证击杀经验、宝箱奖励、3 选 1、基础升级和金币结算同步显示。
- 修改失败辅助时，验证连续失败后敌人血量、速度、刷怪间隔按配置变化。
- 接入体验关脚本时，验证 `level_experience.tscn` 挂载脚本、`level_id` 和下一关路径三者一致。
