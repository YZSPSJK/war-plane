# 玩法核心文档

## 事实来源

- 主玩法脚本：`scripts/levels/level1.gd`
- 体验关扩展脚本：`scripts/levels/level_experience.gd`（当前场景未挂载，见 `level-construction.md`）
- 数值配置：`scripts/config/game_balance.gd`
- 关卡配置：`scripts/config/level_catalog.gd`
- 进度存档：`scripts/core/level_progress.gd`

## 核心循环

1. 进入关卡后 `GameManager.start_game()`，关卡立即开始。
2. 玩家控制底部主角横向移动，主角按固定间隔自动向上发射子弹。
3. 子弹按中间墙体中心线分流：
   - 左侧命中技能池，扣减技能池总血量。
   - 右侧命中敌人，按候选排序选择唯一目标结算。
4. 技能池归零后重置，并从可用技能池中解锁一个技能。
5. 敌人按阶段刷出并持续下压；当前阶段清空后推进到下一阶段。
6. 击杀敌人累计经验，达到阈值后主角升级并提升子弹或已解锁技能。
7. 敌人触碰主角或到达主角水平线时失败；Boss 阶段清空且解锁目标满足时通关。

## 玩家控制

- 移动按钮：`MoveLeft`、`MoveRight`。
- 键盘：`A` / `Left` 左移，`D` / `Right` 右移。
- 触屏：点击或拖动时将主角移动到触点 `x`。
- 主角移动范围限制在 `_play_rect` 内，底部固定高度由 `_layout_world()` 计算。

## 子弹成长

基础字段来自 `GameBalance.progression()`：

- 击杀升级阈值：`[6, 14, 24, 36, 50, 66, 84, 104, 126]`
- 每次升级选择当前最低的子弹分支：
  - 子弹数量：每级 `+1`
  - 子弹速度：每级 `+10%`
  - 子弹伤害：每级 `+20%`
- 若已有解锁技能，每次主角升级还会随机升级一个已解锁技能。

## 敌人阶段

阶段由 `_wave_phase` 表示：

- `0`：普通敌人
- `1`：精英怪
- `2`：Boss

默认流程：

1. 第 `1~5` 波每波先刷普通敌人，再刷精英怪。
2. 第 5 波精英结束后，若关卡仍要求继续解锁技能，则插入解锁机会波。
3. 解锁目标达成或机会耗尽后进入 Boss。
4. Boss 清空后进入通关。

当前实现中普通、精英、Boss 均按随机横向位置逐个刷出；旧文档中的固定矩阵语义仅作为早期原型参考，不作为当前代码事实。

## 技能池

- 左侧技能池以 `10x10` 点阵显示，表达一个共享总血池。
- 当前基础总血量：`skill_pool_max_hp = 500.0`
- 普通、苦无、分身普通弹命中左侧技能池时，每次扣 `damage_to_skill_pool = 10.0`。
- 技能池归零后重置并尝试解锁技能。
- 前 5 关采用顺序解锁模式时，实际解锁顺序由 `LevelProgress.commit_skill_unlock()` 约束。

## 失败与通关

失败条件：

- 活动敌人与主角圆形碰撞。
- 活动敌人的底部到达主角水平线。

失败结果：

- 记录当前关卡失败次数。
- 清空子弹、分身和持续效果。
- 显示失败弹窗。

通关结果：

- 清空当前关失败次数。
- 写入关卡进度并解锁下一关。
- 清空子弹并显示通关弹窗。

## 当前接入差异

- `scripts/levels/level_experience.gd` 定义了救援宝箱和“神罗天征”体验关逻辑。
- `scenes/levels/level_experience.tscn` 当前仍挂载 `scripts/levels/level1.gd`，且没有在场景中设置 `level_id = "level2_experience"`。
- 因此体验关扩展逻辑目前应视为“已编写但未接入场景”的能力，不能作为线上实际玩法事实。

## 验收关注点

- 修改刷怪或阶段推进时，验证普通、精英、Boss 互斥，不出现多个活动阶段同时压场。
- 修改技能池时，验证左侧命中只扣技能池，右侧命中只打敌人。
- 修改成长时，验证击杀阈值、子弹升级、技能升级三者同步显示。
- 修改失败辅助时，验证连续失败后敌人血量、速度、刷怪间隔按配置变化。
- 接入体验关脚本时，验证 `level_experience.tscn` 挂载脚本、`level_id` 和下一关路径三者一致。
