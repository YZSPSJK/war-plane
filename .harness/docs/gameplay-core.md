# 玩法核心文档

## 事实来源

- 当前 H5 入口：`index.html`
- 当前 H5 样式：`web/styles.css`
- 当前 H5 配置：`web/config.js`
- 当前 H5 存档：`web/progress.js`

- 体验关扩展脚本：`scripts/levels/level_experience.gd`（当前场景未挂载，见 `level-construction.md`）

当前可运行入口已调整为 H5。Godot 脚本仍保留为历史实现与规则参考；浏览器版本的运行时规则以 `web/game.js` 为准。

## 核心循环

1. 进入 H5 后先打开小程序式底部菜单；主菜单可开始游戏，战机信息页可解锁或设为出战，默认只解锁基础战机。
2. 玩家控制底部战机横向移动，战机按固定间隔自动向上发射子弹。
3. 子弹按中间墙体中心线分流：
   - 左侧命中宝箱，扣减宝箱血量。
   - 右侧命中敌人，按候选排序选择唯一目标结算。
4. 宝箱归零后重置，先展示奖励宝箱，再触发 3 选 1 奖励选择。
5. 普通敌人与精英怪在每一波中混合刷出并持续下压；下一波生成队列会在上一波刷完后立即接上，不等待屏幕清空。
6. 击杀敌人累计经验，达到阈值后战机等级提升并触发 3 选 1 升级选择；等级提升奖励不出现子弹数量和子弹穿透卡。
7. 战机默认最大血量为 `100`。普通怪触碰战机造成 `5` 点伤害，精英怪造成 `10` 点伤害并移除；Boss 和死神 Boss 接触战机直接失败。死神 Boss 清空后通关并结算金币和抽奖券。

## 玩家控制

- 键盘：`A` / `Left` 左移，`D` / `Right` 右移。
- 触屏：点击或拖动时将战机移动到触点 `x`。
- H5 游戏界面不再显示底部“左”“右”移动按钮。
- 战机移动范围限制在 `_play_rect` 内，底部固定高度由 `_layout_world()` 计算。

## 成长与奖励

- H5 本地存档增加 `drawTickets`、`selectedFighter`、`fighters` 和 `fighterUpgrades`。
- 初始只拥有 `basic_fighter` 基础战机；其他战机可在战机信息页用金币解锁。
- 新存档默认金币为 `999999`。
- HUD 显示本局金币、持有金币和抽奖券。死亡只结算本局金币；通关额外获得 `balance.clearTickets = 1` 张抽奖券。
- 左侧宝箱初始血量配置：`balance.chest.maxHp = 120`；每击碎一次后，下一轮最大血量按上一轮 `* balance.chest.hpGrowthMultiplier = 1.5`，再向上取整到 `balance.chest.hpRoundStep = 100`。
- 普通子弹命中宝箱扣血配置：`balance.chest.damagePerHit = 3`。
- 宝箱击碎后奖励选择轮数概率配置：`balance.chest.rewardCounts`
  - `1` 次：`80%`
  - `3` 次：`15%`
  - `5` 次：`5%`
- 宝箱击碎后先展示对应数量的奖励宝箱。点击每个宝箱后进入 3 选 1，选择后继续下一个宝箱或恢复战斗。
- 击杀经验：普通怪 `1`，精英怪 `6`，Boss `40`，死神 Boss `120`。
- 升级经验阈值配置：`balance.progression.xpRequirements = [16, 34, 58, 88, 124, 166, 214, 268, 328]`，前期升级节奏放慢。
- 升级时提供 3 张基础强化卡，稀有度概率来自 `rarityDefs`，默认蓝色普通 `70%`、紫色史诗 `25%`、橙色传说 `5%`。
- 每个强化的出现权重和稀有度增量来自 `upgradeOptions`。
- 当前只保留基础强化：子弹数量、子弹射速、子弹穿透、子弹伤害、血量恢复；子弹数量和子弹穿透只会出现在宝箱奖励中，且每次固定 `+1`。子弹数量卡为“子弹数 +1，伤害降低25%”。子弹数量最终上限为 `balance.upgradeCaps.bulletCount = 5`，子弹穿透上限为 `balance.upgradeCaps.pierce = 3`。血量恢复按普通 `5`、史诗 `15`、传说 `30` 点立即恢复，且不超过当前最大血量。
- 战机强化页可直接轮播切换各个战机，消耗金币升级基础攻击、射速、攻击数量、血量和命中技能；击败技能只解锁，不继续升级。血量升级每级增加 `20` 点最大血量。升级页提供“重置”按钮，可一键清空当前战机升级进程；基础战机的击败被动仍保持默认状态。

## 战机

- `basic_fighter` 基础战机：无额外加成，默认解锁。
- `flame_fighter` 火焰战机：子弹命中敌人附加持续伤害；击败技能解锁后在死亡位置保留灼烧区域。
- `frost_fighter` 冰霜战机：子弹命中敌人附加减速；击败技能解锁后产生冰片区域，区域内敌人受到伤害并减速。
- `blast_fighter` 爆炸战机：子弹命中敌人时，对命中点周围敌人造成范围伤害；击败技能解锁后产生一次范围爆炸。
- `storm_fighter` 闪电战机：子弹命中敌人时触发闪电链；击败技能解锁后从死亡位置触发一次过载闪电。
- `piercing_fighter` 穿甲战机：连续命中同一敌人时，当前射速逐步提高；切换目标重置，击败技能解锁后可把攻速加成保留到下一目标。
- `fission_fighter` 裂变战机：命中敌人时，对附近最多 3 个敌人造成分裂伤害；击败技能解锁后产生额外分裂。
- `gravity_fighter` 引力战机：命中敌人时击退目标，当前击退距离为旧基础值和升级值的 `8%`；击败技能解锁后在死亡位置生成黑洞，将范围内敌人拉向中心。
- 战机价格和描述维护在 `web/config.js` 的 `fighters`；持续伤害、减速、范围、闪电链、穿甲攻速、裂变和引力数值维护在 `fighterEffects`。

## 敌人阶段

阶段由 `_wave_phase` 表示：

- `0`：普通敌人
- `1`：精英怪
- `2`：Boss
- `3`：死神 Boss

默认流程：

1. 第 `1~5` 波每波按队列混合刷出普通敌人与精英怪。
2. 第 5 波混合敌群结束后进入 Boss。
3. 如果死神 Boss 尚未出现，常规 Boss 清空后继续循环混合波次。
4. 开局 `balance.deathBoss.spawnAfterSeconds = 300` 秒后刷新死神 Boss。
5. 死神 Boss 清空后进入通关。

当前 H5 实现中普通、精英按随机横向位置从页面顶部外侧逐个落入，并由混合队列把精英均匀插入普通怪之间；普通怪基础血量为 `4`，精英怪基础血量为 `8`，以基础战机基础攻击力 `1` 计算分别需要 `4` 次和 `8` 次基础攻击击败。当普通怪当前生成血量小于等于“当前单轮发射总伤害 * 2”并持续 `5` 秒后，后续刷出的普通/精英怪血量提高 `50%`；如果涨血后仍持续满足该条件，可以继续触发下一次 `+50%`。普通怪每波从 `7` 个开始，每波增加 `5` 个，精英怪每波 `8` 个；普通怪刷怪间隔为 `0.54` 秒，精英刷怪间隔为 `0.78` 秒。普通怪基础下压速度为 `7.5`，精英怪基础下压速度为 `9.0`，即普通怪的 `120%`；普通/精英的生成队列连续追加，Boss 仍在前置敌人清空后作为单个大型目标登场并显示血条。旧文档中的固定矩阵语义仅作为早期原型参考，不作为当前代码事实。

## 宝箱

- 左侧宝箱以更立体的橙色霓虹宝箱图案显示，表达一个共享宝箱血量，血条显示在宝箱上方。
- 宝箱奖励池与升级奖励池一致，包含基础弹幕强化和血量恢复。
- 宝箱奖励弹窗和 3 选 1 弹窗打开期间暂停战斗，完成全部奖励选择后恢复。

H5 版本使用 `localStorage.neonTowerProgress` 保存金币、抽奖券、关卡进度、选中角色、选中战机、角色预留数据、战机拥有状态和战机升级状态；Godot 版本使用 `user://level_progress.cfg`。

## H5 视觉规则

- 不再使用 `assets/pixel_skills/` 的像素素材。
- 玩家主体使用当前战机图片绘制，运行时基准尺寸为 `balance.heroSize = 34`，并在机体周身绘制轻量环绕特效；火焰、冰霜、爆炸、闪电、穿甲、裂变和引力战机分别使用不同的轨道标记。
- 宝箱使用橙色霓虹宝箱图案表达，宝箱上方显示血条，不显示数字血量。
- 手机宽度下，宝箱/敌人/金币等状态卡片压缩到顶部 HUD 区域，避免遮挡左侧宝箱。
- 宝箱击碎奖励弹窗使用烟花、彩蛋、星火和宝箱图标；3 选 1 卡片按强化内容显示不同图标，奖励界面减少额外内框线。
- 敌人素材来自 `assets/meteors/`：普通怪使用像素熔岩陨石，精英怪使用像素尖锐陨石，Boss 和死神 Boss 使用无拖尾的超大像素陨石；普通和精英不显示血条，Boss 和死神 Boss 显示血条。Boss 的压迫感由 Canvas 光晕、脉冲圈和大尺寸绘制表达，不在素材中绘制拖尾。普通/精英/Boss/死神 Boss 运行时碰撞半径分别为 `8 / 10 / 56 / 68`。
- H5 Canvas 使用 `visualViewport` 与设备像素比渲染，并在 CSS 中使用 `100dvh`/安全区变量适配 iPhone Safari 高度和刘海安全区。
- 火焰灼烧区域、冰霜冰片区域和闪电链均在 Canvas 上绘制短时可见效果。
- 中央道路与墙体使用青色霓虹描边和扫描线。
- H5 背景使用缓存画布绘制，避免每帧重复绘制大量背景线条；高频子弹和战机绘制不使用大范围阴影。

## 失败与通关

失败条件：

- 战机血量归零。
- Boss 或死神 Boss 与战机圆形碰撞或到达战机水平线。

失败结果：

- 记录当前关卡失败次数。
- 清空子弹、分身和持续效果。
- 显示失败弹窗，提供“重试”和“返回主界面”。

通关结果：

- 清空当前关失败次数。
- 写入关卡进度、金币、抽奖券并解锁下一关。
- 清空子弹并显示通关弹窗。

## 当前接入差异

- `scripts/levels/level_experience.gd` 定义了救援宝箱和“神罗天征”体验关逻辑。
- `scenes/levels/level_experience.tscn` 当前仍挂载 `scripts/levels/level1.gd`，且没有在场景中设置 `level_id = "level2_experience"`。
- 因此体验关扩展逻辑目前应视为“已编写但未接入场景”的能力，不能作为线上实际玩法事实。

## 验收关注点

- 修改刷怪或阶段推进时，验证普通、精英、Boss 互斥，不出现多个活动阶段同时压场。
- 修改宝箱时，验证左侧命中只扣宝箱，右侧命中只打敌人。
- 修改成长时，验证击杀经验、宝箱奖励、3 选 1、基础升级、金币和抽奖券结算同步显示。
- 修改战机时，验证初始只解锁基础战机，金币解锁、选择和对应命中特效均生效。
- 修改失败辅助时，验证连续失败后敌人血量、速度、刷怪间隔按配置变化。
- 接入体验关脚本时，验证 `level_experience.tscn` 挂载脚本、`level_id` 和下一关路径三者一致。
