# Combat Hit Logic Spec (Level 1 Baseline)

## 1. 坐标系与分区

- 场景为 `Node2D`，主角与子弹在世界坐标更新。
- 以中间墙体中心线为分区边界：
  - 子弹 `x < wall_center_x`：左侧技能区判定。
  - 子弹 `x >= wall_center_x`：右侧敌人区判定。

## 2. 矩阵定义

- 左侧技能区：固定 `10x10` 矩阵显示，仅作为总血池可视化，不做单格独立血量。
- 右侧普通敌人：`10xn`，并保证数量始终为 10 的倍数。
- 右侧精英怪：`4x4` 点阵，右侧区域水平居中。
- 右侧 Boss：`6x6` 点阵，右侧区域水平居中。

## 3. 阶段推进（互斥）

- 第 1~5 波按以下顺序推进：
  - 普通敌人阶段（`10xn`）
  - 精英怪阶段（`4x4`）
- 第 5 波精英结束后进入 Boss 阶段（`6x6`）。
- 同一时刻只存在一个活动敌人矩阵（普通 / 精英 / Boss），避免垂直重叠。

## 4. 子弹命中与排序

- 单发子弹只参与一次命中结算；命中后立即消失，不参与多个敌人判定。
- 子弹有起飞距离阈值，超过阈值后才参与命中判定。
- 右侧敌人命中采用“接触判定”（子弹圆与敌人点半径重叠）。
- 若同一帧命中多个候选目标，按以下顺序选择唯一目标：
  - 第一关键字：`x` 从小到大（左到右）
  - 第二关键字：`y` 从大到小（下到上）

## 5. 伤害结算规则

设怪物剩余血量为 `A`，子弹伤害为 `B`：

- `A <= B`：怪物血量置零并移除，子弹消失。
- `A > B`：怪物新血量为 `A - B`，子弹消失，怪物保留。

左侧技能区总血池同样遵循单弹单判：命中一次仅扣一次伤害。

## 6. 失败与显示规则

- 任一活动敌人触碰主角：游戏结束。
- 任一活动敌人下压到主角水平线：游戏结束。
- 右侧红色浮动数字显示“当前活动敌人矩阵总血量”，跟随当前活动敌人中心上方。
